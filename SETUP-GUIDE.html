HP1VR V31 — from download to PC VR

Frame and independent aiming candidate, October 18, 2026. Matched runtime binaries rebuilt; headset acceptance pending. This is HP1, not HP2. The guide works offline; external download links require internet.

New installer help: Verify inputs fills a component table. Double-click any row for exact detected paths and corrective instructions. Full installation repeats validation before copying. Use original textures explicitly if you do not want the ESRGAN pack. Open full log and Copy result details preserve failure information. Install.cmd uses a process-only PowerShell policy; stored policy and antivirus settings are not changed.

Frame bindings, calibration, save transfer and rollback (open the Markdown file in Notepad if your browser downloads it). Frame View opens game menu; right grip + View opens VR options. Expand Controller Aim / Frame for separate wand/pointer angles. Keep your previous working installation.

Base game required: the compatibility reference is the separate HP1 MagiPack distribution from MyAbandonware, for Harry Potter and the Philosopher's Stone / Sorcerer's Stone. It is NOT the Chamber of Secrets MagiPack. No base-game files or download links are supplied. The local HP1 copy matches all eight engine/script checks. A fresh installation of this updated package still needs headset acceptance.

1. Download our mod

  1. On the author's HP1VR GitHub repository, open Releases and expand Assets.
  2. Download the packaged mod-only ZIP, not GitHub's automatic Source code archive. A verified public repository URL has not been embedded in this package; use the author's own release link.
  3. Right-click the ZIP in File Explorer, choose Extract All, and extract to a writable folder such as Documents.
  4. Open the extracted folder until you see Install.cmd, Setup.ps1, Install.ps1, config, and payload. Keep them together; do not run inside the ZIP.

2. Prepare your HP1 game

  1. Install or fully extract your own Windows PC HP1 game. If your downloaded archive contains a setup program, extract first, then run that program.
  2. Find the installed folder containing System and Maps. Do not select an archive, setup EXE, or System alone.
  3. Keep game versions separate. Another distribution may work if its engine/scripts match; the installer does not assume every region or patch is compatible.
HP1 game root ← select this
  System\Core.dll
  System\HarryPotter.u
  Maps\Lev_Tut1.unr
  Textures\
  Sounds\
  Music\

Setup checks Core.dll, Engine.dll, WinDrv.dll, Galaxy.dll, Fire.dll, HPBase.u, HarryPotter.u, and HPMenu.u. These are compatibility checks, not a complete game. Keep all game data. dgVoodoo is not required: the installer excludes its wrapper DLLs and supplies the separately obtained DX11 renderer. Do not add the HP2 renderer to HP1.

3. Download HP1 DX11 Renderer 1.6.2

  1. Open the HP1 renderer 1.6.2 download page.
  2. Download hp1dx11renderer162.zip and extract all contents.
  3. Find Common and Harry Potter 1 together. Select their parent under Renderer.
Extracted renderer ← preferred selection

  Common\Effects11.dll
  Common\d3d11drv\...all shaders...
  Harry Potter 1\d3d11drv.dll
  Harry Potter 1\tessellation.cfg

Nearby Common or Harry Potter 1 selections are recognized if the matching files are adjacent. A prepared game/System layout is supported only if all checked files, including the original renderer tessellation.cfg, match. Existing VR settings may have replaced that file; use a clean extracted download if so. Setup logs each resolved file. Quoted pasted paths are accepted. A DLL alone is insufficient.

4. Download the HP1 ESRGAN v3 texture pack

  1. Open Akven's HP1 ESRGAN Upscale Pack v3.
  2. Download and extract the entire archive with an archive tool supporting its format.
  3. Select the extracted pack root containing Textures and System. Selecting Textures directly also works when its sibling System folder is intact.
Extracted HP1 ESRGAN v3 ← preferred selection
  Textures\...DDS files...
  System\tessellation.cfg

This pack is recommended for the intended enhanced appearance. Do not use the HP2 pack and do not delete original UTX packages. To skip it, check Use original textures in setup (CLI: explicitly pass empty TexturePackRoot). That fallback works but does not provide the enhanced texture appearance.

5. Microsoft prerequisites

  1. Open Visual C++ 2010 SP1 MFC Security Update, click Download, choose vcredist_x86.exe, and run it. Use x86 even on 64-bit Windows. Restart if requested.
  2. Open DirectX End-User Runtimes June 2010. Download and run directx_Jun2010_redist.exe to extract into a temporary folder.
  3. Open that folder and run DXSETUP.exe. Extraction alone is not installation.

These libraries coexist with modern Windows DirectX. Do not download random replacement DLLs. Setup checks the x86 runtime files, but file presence is not a full health test. The Microsoft installers run separately, not silently through HP1VR.

6. SteamVR and OpenVR

  1. Install Steam and SteamVR.
  2. Install your headset's PC connection software as required, connect the headset/controllers, and verify tracking in SteamVR.

This HP1 package already includes its tested OpenVR client DLLs and Valve license. No separate OpenVR SDK selection is needed. Do not replace them with HP2 files. OpenVR does not replace SteamVR. Quest requires PC VR; this is not a standalone APK.

7. Verify and install

  1. Close HP1 and VR processes. Run Install.cmd.
  2. Use the download buttons if anything above is missing. Full instructions opens this guide.
  3. Game: select the installed HP1 root containing System and Maps.
  4. Renderer: select the extracted Common/HP1 parent.
  5. Textures: select the extracted HP1 ESRGAN v3 pack root.
  6. Destination: enter a separate new folder name, such as Documents\HP1VR-Play. Do not choose the mod kit or an input folder. Existing nonempty destinations are refused.
  7. Click Verify inputs. Install is enabled only after successful verification; changing an input requires verification again.
  8. If a check fails, read the current stage and exact file in the status area. Use Open full log or Copy result details. Fix the input, then verify again.
  9. Click Install V31 and wait for the explicit installed result. Setup copies your game, renderer, texture pack, and VR components into the separate destination. Original source files are not modified.

If installation fails after copying starts, keep the incomplete folder and logs. Do not launch a folder containing INSTALL-INCOMPLETE.txt. Retry into a different destination. The installer does not disable antivirus or upload logs.

8. First headset run

  1. Connect the headset/controllers and start SteamVR.
  2. Open the newly installed folder and launch Launch-HP1-VR-V31.exe, not the original game's EXE or the launcher's copy inside the mod kit.
  3. Stand upright for calibration. Check the complete stationary menu and right-hand pointer/trigger interaction.
  4. Start New Game. Verify head tracking, movement, wand interaction, and menu/game transitions. These require a headset test; successful installation is not proof of gameplay.
  5. Open VR settings with left Y plus right grip on Touch controllers. Read CONTROLS.md and SETTINGS.md for other interactions and bindings.

Next time, start SteamVR and use the same installed launcher. No reinstall is needed. Back up Runtime/Save and Runtime/VR/V31Calibration.ini. Separate installations do not synchronize saves.

9. Updating and saves

Install updates into another separate empty folder. This HP1 installer does not have HP2's automatic Update from workflow. Close both copies and back up first. Migrate Save*.usa and associated GameSaveInfo* files to Runtime/Save. Preserve V31Calibration.ini; older V31 installations may name it V30Calibration.ini, which can be copied under the V31 name without changing its internal section. Keep the old installation until the new one is verified.

10. Fix missing or incompatible inputs

  • Missing renderer file: extract the complete HP1 archive. Select the parent containing Common and Harry Potter 1. The error lists searched paths.
  • Renderer mismatch: use HP1 1.6.2, not HP2 or another revision. Nearby folders are accepted only when the files verify.
  • Texture missing/mismatch: use HP1 ESRGAN v3 and retain both Textures and System. Do not select a ZIP or the HP2 pack.
  • Unsupported engine/script: save the exact named-file/hash error for compatibility review. Do not mix game DLLs or bypass checks.
  • Missing runtime: run the Microsoft installers from step 5, then verify again.
  • Copy/permission/security failure: read the log's stage, path, and exception. Use a writable destination. Do not disable security or add broad exclusions.
  • Startup error: inspect Runtime/VR/compositor.log and Runtime/System/HP1VRHost.log. Code 7 alone does not identify a SteamVR failure.

Logs include local paths/usernames. Review before sharing. Publish only the mod kit, never the installed game, personal saves, or a dependency test collection. See LICENSE and LICENSE-STATUS.md for license terms. No fresh HP1 headset acceptance is claimed by this installer update.
